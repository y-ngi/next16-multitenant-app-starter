# プロダクト概要

## 目的

本プロジェクトは、マルチテナント SaaS および Web アプリケーションを迅速に立ち上げるためのスターターテンプレートです。初期段階では Next.js をフルスタックのモノリスとして利用し、開発速度と運用の単純さを優先します。

## コア機能

- メールアドレス／パスワード認証、メール検証、二段階認証を備えた認証基盤
- 組織（テナント）とユーザーの所属・ロールを分離して扱うマルチテナント用データモデル
- 認証済みユーザー向けの保護ページとセッション表示のサンプル
- 再利用可能な UI プリミティブによる管理画面・フォームの構築基盤

## 主な利用シナリオ

- 組織ごとにデータと権限を分離する SaaS の初期実装
- 複数組織に所属できるユーザーを扱う業務 Web アプリケーション
- 認証、データベース、UI、テスト基盤を備えた Next.js プロジェクトの出発点

## 価値提案

共通で難度の高い認証・組織管理・開発品質の基盤を先に整え、個別のドメイン機能へ集中できるようにする。ビジネスロジックと認証・永続化の責務を分離し、将来的にフロントエンドと API を分割できる拡張性も維持する。
